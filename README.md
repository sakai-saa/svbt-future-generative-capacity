# svbt-future-generative-capacity
SVBT detects irreversible loss of future-generative capacity beyond an agent’s current evaluation scope.
## Research Question

How can an AI system detect irreversible loss of future-generative capacity before those future possibilities are represented or evaluable?

## Current Experiments

Current experiments test whether preserving or destroying generative conditions changes the set of future possibilities that remain reachable.

Focus areas include:
- irreversible loss
- generative conditions
- recovery
- substitutability
- cross-model replication
